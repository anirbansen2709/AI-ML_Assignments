## Detailed Project Descriptions

### 1. Deep Neural Networks (DNN)
- **Dataset:** Breast Cancer Wisconsin (569 samples, 30 features)
- **Task:** Malignant vs Benign tumor classification
- **Approach:** Compare linear models with multi-layer perceptrons
- **Key Metric:** Recall (medical diagnosis prioritizes detecting all cancer cases)

### 2. Computer Vision - Handwritten Recognition
- **Dataset:** EMNIST Letters (20,000 images, A-Z)
- **Techniques:** HOG, LBP, histogram equalization
- **Models:** Logistic Regression, KNN, SVM, Random Forest
- **Implementation:** Real handwritten sample classification

### 3. CNN Assignment
- Focus on convolutional neural network architectures for image data

### 4. RNN Assignment
- Focus on recurrent and LSTM networks for sequential data
